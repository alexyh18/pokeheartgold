# 배틀트리 (USUM Battle Tree) — Android

포켓몬 울트라썬·울트라문의 배틀트리(싱글)를 떼어낸 단독 실행 안드로이드 게임. 개인 학습/소장용 팬 프로젝트입니다. 배포 금지.

- 앱을 켜면 바로 렌탈 포켓몬 6마리 중 3마리를 고르는 화면부터 시작 (저장된 도전이 있으면 이어서)
- 싱글배틀 · Lv.50 고정, 7연전 = 1라운드, 패배 전까지 무한 반복
- 포켓몬을 고르기 전 다음 상대 정보 공개: 1라운드 3마리 전부, 2라운드 2마리, 3라운드 선두와 기술 1개, 4라운드부터 주 사용 타입
- 승리 후 쓰러뜨린 트레이너의 포켓몬과 1마리 교환 가능
- 연승·최고 기록·교환 횟수·파티는 매 단계 자동 저장
- 포켓몬 풀은 **배틀트리에 실제로 등장하는 세트**(947세트 · 245종). 트레이너는 각자 정해진 연승 구간에서만 등장
- 7세대 메커니즘: 페어리 타입 포함 18타입 상성, Gen7 종족치/기술/특성/도구

## 설치

`release/usum-battle-tree-v1.9.apk`를 휴대폰에 받아 설치합니다(“출처를 알 수 없는 앱” 허용 필요, Android 7.0 이상).

## 출처

| 내용 | 출처 |
|---|---|
| 배틀트리 세트·트레이너 데이터 | [cristiannomartins/Tree-Sets](https://github.com/cristiannomartins/Tree-Sets) (SM/USUM Battle Tree 카탈로그, CSV/TSV) |
| 종족치·기술 수치·타입상성·한국어 이름·스프라이트 | [PokéAPI](https://pokeapi.co/) (7세대) · PokeAPI CSV 덤프 |
| 배틀 엔진(데미지·급소·명중·스피드·상성·특성·도구) | 자작 코틀린 엔진 (bw2 기반 Gen5 엔진을 Gen7/페어리로 각색) |

## 빌드 / 데이터 생성

```sh
source tools/env.sh                 # JDK17 + Android SDK 경로 설정
python3 tools/extract_usum.py       # Tree-Sets + PokeAPI -> app/src/main/assets/{data,sprites}
./gradlew assembleRelease           # release/usum-battle-tree-vX.Y.apk
```
`tools/apicache/`에 PokeAPI 응답이 캐시되므로 재실행은 네트워크 없이 빠르게 됩니다.

## 구현 참고

- bw2 배틀서브웨이 프로젝트(`../bw2-factory`)와 **완전히 독립**된 별도 프로젝트입니다.
- Gen5 엔진을 가져오면서 **페어리 타입(id 17)**을 타입 상성표(18×18)에 추가했고, 도구 id를 PokeAPI 체계로 재정의했습니다.
- Rotom·Oricorio·Lycanroc의 폼 세트는 기본 폼으로 매핑. 메가 포켓몬은 스프라이트가 기본 폼을 재사용(종족치·타입·특성은 메가로 변경).

## v1.9 변경점

- **용의춤·명상 등 랭크업 변화기가 실패하던 버그 수정** — 추출 데이터의 effect(`RAISE_STATS`/`STAT_CHANGE`)를 엔진이 인식하지 못해 "하지만 실패했다!"로 처리되던 문제를 바로잡음. 이제 칼춤·용의춤·명상·나쁜음모·고속이동 등 자신 능력을 올리는 변화기가 정상 발동합니다
- **변화기를 Z기술로 사용할 때의 Z효과 구현** — 변화기 Z기술은 원래 효과에 더해 Gen7 Z보너스가 발동합니다. 능력 상승기는 특정 능력 +1, 회복기는 HP 완전 회복, 흑안개는 자신의 능력 하락 초기화 등(용의춤→공격 +1, 명상→특수방어 +1 등 전 변화기 매핑)
- **기술 설명 표시** — 기존에 비어 있던 기술 설명을 한국어로 채워 넣음(전 447개 기술). 배틀 중 기술을 **길게 누르면** 설명이 표시됩니다
- 렌탈/교체 화면 UI 정리 — 포켓몬 이름이나 타입 이름이 길어도 카드가 깨지지 않도록 이름은 말줄임(…) 처리하고 타입 배지 위치를 고정, 모든 카드 높이를 균일하게 맞춤

## v1.8 변경점

- **불비달마 달마모드(Zen Mode) 특성 구현** — HP가 절반 이하가 되면 달마모드(불꽃/에스퍼, 특공형 종족값)로 폼체인지하고, HP가 절반을 초과하면 원래 모습으로 돌아옵니다. 교체로 물러나면 원래 모습으로 리셋되며 재진입 시 HP에 따라 다시 판정됩니다(메가진화와 달리 가역적). 전용 스프라이트·이름 표시 지원
- **딱구리 알로라폼 이름 수정** — `폭타(알로라)`로 잘못 표기되던 것을 `딱구리(알로라)`로 바로잡음
- **미래예지(퓨처어택) 지연 공격 수정** — 추출 데이터상 effect가 `NONE`이라 즉시 발동되지 않던(지연 공격 로직이 죽어 있던) 문제 수정. 이제 사용한 턴에는 피해가 없고 2턴 뒤에 공격이 명중합니다(파멸의소망 포함)

## v1.7 변경점

- 위력 변동 기술이 데이터상 effect가 `NONE`이라 발동 안 되던 문제 수정 — 추출기에서 올바른 effect를 부여:
  - 기사회생·바둥바둥(HP 낮을수록↑), 분화·해수스파우팅(자신 HP 비례), 어시스트파워·어태커파워(자신 랭크업 수), 객기(상태이상 시 2배), 리벤지·눈사태·승부굳히기(피격 시 2배), 보복(후공 시 2배), 베놈쇼크·병상첨병(상대 상태이상 시 2배), 쥐어짜기·조이기·혼내기·마지막수단·자연의은혜·내던지기 등
- **대폭발·자폭 사용 시 사용자가 쓰러지지 않던 문제 수정**(상대를 쓰러뜨려 배틀이 끝나는 더블 KO 상황에서도 사용자가 정상적으로 쓰러짐). 축축함 특성에겐 막힘
- 헤비봄버·속임수·자이로볼 동작 점검·검증 완료(각각 무게비·상대 공격·속도비 반영 정상)

## v1.6 변경점

- 메가진화한 포켓몬이 **교체로 물러났다 다시 나와도 메가폼을 유지**하도록 수정(타입·종족치·특성·스프라이트·이름 모두 유지). 7세대 규칙대로 한 번 메가진화하면 그 배틀 동안 지속

## v1.5 변경점

- 매 라운드 첫 렌탈 6마리에 **메가스톤을 지닌 포켓몬이 반드시 1마리** 포함되도록 보장(항상 메가진화 가능)
- 메가진화 시 **메가폼의 특성이 등장 특성으로 즉시 발동**하도록 수정(가뭄·눈퍼뜨리기·모래날림·위협 등). 예: 메가 눈설왕→싸라기눈, 메가 썬더볼트→위협
- 메가진화 후 **방어(Protect)가 발동하지 않던 문제** 수정(마지막에 행동해도 방어는 성공하도록 — 7세대 규칙에 맞춤)

## v1.3 변경점

- **폼체인지 구현**: 알로라폼(나인테일·라이츄·고지·폭타·질퍽이·닥트리오·나시·텅구리), 로토무 5폼(히트·워시·프로스트·스핀·커트), 춤추새 4스타일, 루가루암(한낮·한밤)을 각각 **고유 타입·종족치·특성·스프라이트**를 가진 별도 폼으로 구현(기존엔 기본폼으로 잘못 매핑됨)
- **따라큐 "탈"(Disguise) 배틀 중 폼체인지**: 첫 피격을 무효화하고 탈이 벗겨진 모습으로 변함(최대 HP 1/8 감소)
- **스프라이트를 정적 픽셀(도트) 스프라이트로 교체**: 애니메이션 GIF → PokeAPI 2D 픽셀 스프라이트(front_default). 메가·폼 스프라이트도 동일 적용
- (버그 수정) 지진·파도타기 등 **광역 공격기(target=ALL)가 "실패"하던 문제** 수정 — 싱글배틀에서 상대를 정상 타격

## v1.2 변경점

- **메가 스프라이트** 적용: 메가진화 시 기본 폼이 아니라 각 메가폼 고유 스프라이트(PokeAPI 메가 아트)를 표시
- **변화기 Z** 구현: 변화기도 지닌 Z크리스탈과 타입이 맞으면 Z기술로 사용 가능. 원래 효과를 발동한 뒤 Z보너스(자기 강화기는 해당 능력치 +1)
- 전용 Z기술 틀 추가(단, 배틀트리 풀의 세트는 모두 **범용 타입 Z크리스탈**만 지녀서 전용 Z는 발동하지 않음 — 전용 크리스탈이 없음)
- **7세대 배틀 메커니즘 보강**:
  - 급소 데미지 1.5배(기존 2배) + 7세대 급소 확률 테이블(1/24·1/8·1/2·확정)
  - 마비 시 스피드 1/2(기존 1/4)
  - 강철 타입이 더 이상 고스트·악을 반감하지 않음(6세대 상성 반영)
  - **필드**(일렉트릭·그래스·미스트·사이코) 구현: 접지 포켓몬에게 해당 타입 1.5배, 그래스필드 매턴 회복·지진류 반감, 미스트필드 상태이상 무효, 일렉트릭필드 잠듦 무효, 사이코필드 선제공격기 무효
  - **짓궂은 마음**: 변화기 우선도 +1, 악 타입은 면역

## v1.1 변경점

- **메가진화** 구현: 메가스톤을 지닌 포켓몬이 배틀 중 1회 메가진화 → 종족치·타입·특성이 메가폼으로 변경(스피드 변화는 행동 순서 전에 적용). 기술 선택 화면의 "메가진화" 토글로 발동, 교체 시 원래 폼으로 복귀. 메가폼 42종 데이터
- **Z기술** 구현: 해당 타입 Z크리스탈을 지닌 포켓몬이 같은 타입 공격기를 배틀당 1회 Z기술로 강화(Gen7 위력표: 예 위력 90 → 175). "Z기술" 토글 + 해당 기술 선택으로 발동. 18타입 Z크리스탈
- 상대 AI도 가능하면 메가진화하고 최선의 기술에 Z기술 사용
