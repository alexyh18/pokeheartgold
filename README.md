# 배틀서브웨이 (BW2 Battle Subway) — Android

BW2 배틀서브웨이의 슈퍼싱글을 떼어낸 단독 실행 안드로이드 게임. 개인 학습/소장용 팬 프로젝트입니다. 배포 금지.

- 앱을 켜면 바로 슈퍼싱글 1번째 열차의 렌탈 선택부터 시작 (저장된 도전이 있으면 이어서)
- 싱글배틀 · Lv.100 고정, 7연전 = 1열차, 패배 전까지 무한 반복
- 포켓몬을 고르기 전 다음 상대 정보 공개: 1라운드 3마리 전부, 2라운드 2마리, 3라운드 선두와 기술 1개, 4라운드부터 주 사용 타입
- 승리 후 상대 포켓몬과 교환, 7열차(49전째) 마지막 칸에 배틀서브웨이 보스(Ingo) 등장
- 연승·최고 기록·교환 횟수·파티는 매 단계 자동 저장
- 1~5세대 포켓몬 296종, 기술 414개·특성 124개·도구 106개 구현

## 설치

`release/bw2-battle-subway-v2.7.apk`를 휴대폰에 받아 설치합니다(“출처를 알 수 없는 앱” 허용 필요, Android 7.0 이상).

## v2.7 변경점

- 헤롱헤롱(헤롱헤롱바디 포함) 메커니즘 수정: 상대(반한 대상)가 쓰러지거나 교체로 필드를 떠나면 헤롱헤롱이 풀리고, 운명의매듭이면 상대도 헤롱헤롱에 걸림
- 잠든 상태 전용 기술 수정: 코골기도 잠든 상태에서 쓸 수 있게 됨(기존엔 잠꼬대만 허용), 코골기·잠꼬대는 깨어 있을 때 쓰면 실패

## v2.6 변경점

- 배경을 **일반 싱글 배틀용 필드**로 교체 (이전 배경은 로테이션 배틀용 2중 플랫폼이었음)
- 상태창의 "Lv100"·HP 수치가 잘리던 문제 수정 (HUD 기울기·여백 조정)
- 상성 메시지 세분화: 4배 "효과가 매우 굉장했다!", 1/4배 "효과가 매우 별로였다…"
- 기술 선택창에 상대 기준 상성 표시 (효과가 매우 굉장/굉장/별로/매우 별로/효과 없음)
- "필드 정보" 버튼 추가: 날씨·트릭룸·중력, 양쪽의 설치기(스텔스록·압정)와 벽(리플렉터 등), 각 포켓몬의 랭크 변화 확인

## v2.5 변경점

- 배경을 배틀서브웨이 스테이지(화살표 플랫폼)로 통일 — 보스전도 밤하늘 대신 서브웨이 스테이지 사용
- 배틀 화면을 더 자연스럽게: 포켓몬 등장 슬라이드·발밑 그림자, BW2풍 프레임 메시지창, 상태창에 상태이상 배지 위치 정리
- 도구 효과 점검 및 누락분 보강: 불꽃구슬(자기 화상), 풍선(땅 면역·피격 시 터짐), 울퉁불퉁멧(접촉 반동), 자뭉/비자/수진열매 추가 — 왕의징표석/예리한손톱(풀죽음), 구애 계열, 기합의띠, 생명의구슬, 약점보험(저항)열매 등은 기존 동작 확인

## v2.4 변경점

- 포켓몬 레벨을 50 → **100**으로 조정 (노력치·개체값·성격·기술배치·도구는 그대로, 레벨에 따라 능력치만 재계산)

## v2.3 변경점

- 슈퍼 코스 풀 중에서 **최종진화체가 아닌 포켓몬은 제외**하되, 폴리곤2만 예외로 유지 (적격 812세트·222종)

## v2.2 변경점

- 등장 포켓몬을 **슈퍼 싱글 코스 세트**로 한정 (슈퍼 트레이너 index 110~299 + 보스가 쓰는 820세트·230종). 슈퍼 코스 풀에 있으면 최종진화체가 아니어도 등장(폴리곤2, 디헤드 등 9종 포함)

## v2.1 변경점

- **연승 포기**: 화면 상단 "포기" 버튼으로 현재 연승을 접고 1번째 열차부터 다시 시작(최고 기록은 유지)
- **배틀 중 포켓몬 요약**: 배틀의 포켓몬 창에서 각 포켓몬을 탭하면 능력치(랭크 변화 화살표 포함)와 기술 배치(타입·분류·위력·명중·PP) 확인
- **최종진화체만 등장**: 진화가 남은 포켓몬(폴리곤2, 두까비 등 75종)은 렌탈·상대에 나오지 않음
- **배틀 UI를 BW2 스타일로**: 비스듬한 HP 상태창·HP바·상태이상 아이콘·상대 파티 표시를 BW2 모양으로 다시 그림(코드로 직접 그린 오리지널 UI)

## v2.0 변경점

- 포켓몬을 HGSS 배틀팩토리 세트에서 **BW2 배틀서브웨이 슈퍼싱글** 세트로 전면 교체 (4세대 한정 → 1~5세대 전체)
- 배틀 엔진에 5세대 기술·특성을 대거 추가 (매직가드/위협/자기과신/하복/의욕/하늘의은총/모래먼지 가속 등, 신규 기술 효과 다수)
- 팩토리헤드(Thorton) → 배틀서브웨이 보스(Ingo)

## 빌드

```sh
python3 tools/extract.py              # ../pokebw2 저장소가 있어야 함
python3 tools/trainer_sprites.py      # Pillow 필요
./gradlew assembleRelease             # app/build/outputs/apk/release/app-release.apk
```

## 구조

- `engine/` — 배틀 엔진(순수 Kotlin): `Battle.kt`(턴 진행·기술·특성·도구), `Ai.kt`(상대 AI), `Core.kt`(상성표·능력치·한국어 조사)
- `factory/` — 슈퍼싱글 규칙(`FactoryRules.kt`)과 진행/저장 상태(`FactoryState.kt`)
- `ui/` — Jetpack Compose 화면(렌탈, 대전 전, 배틀, 교환, 라운드 클리어, 패배)
